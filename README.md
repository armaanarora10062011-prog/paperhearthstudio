# paperhearth

Static Paperhearth site with three working demo buttons.

- `index.html` — main Paperhearth site
- `demos/web/index.html` — Premium Web Presence demo
- `demos/ops/index.html` — Operations Sprint demo
- `demos/lead/index.html` — Lead Engine demo
- `source-demos/` — original supplied demo ZIPs preserved for reference

This version is intentionally static so it can deploy directly without an npm/Vite build step.
