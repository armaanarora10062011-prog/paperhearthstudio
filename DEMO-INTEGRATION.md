# Paperhearth demo integration

The three supplied demos are embedded in the main Paperhearth site and opened from the service-card `View demo` buttons:

- Premium Web Presence → Northline Studio website demo
- Lead Engine → lead generation workflow demo
- Operations Sprint → Northline Studio automation demo

The demos remain local/simulated and do not require external APIs. Their original React component/data structure is preserved under `src/embedded/`.

Contact email is configured as `team@paperhearth.studio` in `src/config.ts`.
